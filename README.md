# Ralph Leo Portfolio — V4

Interactive static portfolio for GitHub Pages.

## Deploy
Upload the contents of this folder to the existing `Ralufu-Lieou/ralphleo-portfolio` repository, replacing the current files. Keep the repository's GitHub Pages settings and custom domain unchanged.

## V4 direction
- Ralph's portfolio PDF is the content/identity source.
- The Diya Gupta / Wall of Portfolios reference is used as an interaction benchmark, not copied visually.
- Vanilla HTML/CSS/JS; no build step.
- Interactive portfolio finder, hover previews, magnetic links, scroll progress, animated metrics, AI workflow selector, case-study modal, responsive behavior.
